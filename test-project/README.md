# Test Project · FlowNote 演示项目

这里是 RelayForge 的离线演示模板。应用默认从模板生成独立的 Git 项目 `test-project/.runtime/flownote/`，不会修改 RelayForge 自己的分支。打包应用的演示工作目录位于 `~/.relayforge/test-project/`。

`project/` 是可运行的轻量任务板：直接打开 `src/index.html`，可新增任务、切换状态、筛选、设置优先级和导出 JSON，数据保存在浏览器本地。无需依赖或网络。

应用首次打开会准备以下虚构示例，不调用模型：

- 6 个需求覆盖立项中、进行中、待验收、已完成、已取消。
- 3 个层、5 个模块、10 个功能点、5 条用户旅程，含跨模块关系与依赖。
- 需求说明、验收条件、影响分析、适用裁定和文档登记。
- 草稿与现行设计稿，含可操作的单文件 HTML 预览。
- 需求进度、计划、方向调整、日常聊天和大图编辑示例。

在 UI 中打开示例会话只显示演示记录，不调用真实 AI。点击「开始真实会话」才会使用设置里的 Claude Code 或 Codex；新建需求与新聊天也会调用真实工具。

模板数据是虚构情境，示例的完成与取消状态不代表真实用户验收。生成器只创建一个全新的目录；已有目录会保留，不自动覆盖或重置。`build_demo.py` 的 `--target` 可指定一个新的演示目录。

```sh
python3 -B test-project/build_demo.py --target /tmp/flownote-demo --backend backend/rf.py
```

演示建议：先看五列需求看板（左侧会话列表的筛选不影响看板） → 打开「任务截止日期提醒」看进展 → 打开「每周完成趋势」看清晰度、影响与设计稿 → 到大图切换三个层并点击模块看旅程 → 看已完成需求的设计稿与完成记录 → 看已取消需求的内容和恢复入口 → 切到聊天查看示例记录。
