# 演示路线

1. 看需求看板：立项、开发、验收、完成和取消五种状态。
2. 打开「任务截止日期提醒」：检查需求与计划进度，查看一次方向调整。
3. 打开「每周完成趋势」：看清晰度阶梯、依赖影响、适用裁定和可交互设计稿。
4. 切换大图各层，点击模块查看用户旅程；点击跨层步骤会定位相关功能。
5. 打开已完成的「添加任务优先级」查看完成记录和现行设计稿。
6. 打开已取消的「团队账号与云同步」，观察只读详情。
7. 切换聊天，查看排查问题和讨论交互的两个示例会话。
8. 需要实际改代码时，点击「开始真实会话」，或新建一个需求。

演示记录是预先准备的虚构数据，不是正在执行的 Agent。模型调用只在明确开启真实会话之后发生。
