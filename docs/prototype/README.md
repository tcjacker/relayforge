# RelayForge 工作台原型（源文件）

这里保存的是 2026-11 设计讨论中做出的可交互原型的源文件。

- 这些 `.dc.html` 文件依赖 claude.ai 的设计画布运行时，**不能直接用浏览器打开**。它们留在这里是为了不丢失页面结构、对象和交互的设计，以后实现时可以对照。
- 各页面的数据互不相通，内容是演示数据。

| 文件 | 页面 |
|---|---|
| `New.dc.html` | 新建产品：从零开始，或接入已有仓库 |
| `Home.dc.html` | 首页：等你处理、需求队列、产品介绍 |
| `Main.dc.html` | 产品功能：结构树与功能点详情 |
| `Progress.dc.html` | 需求：影响、PRD 增量、开发任务、验收任务 |
| `Control.dc.html` | 研发管控：正在执行与问题清单 |
| `Context.dc.html` | 设计资料：`docs/` 目录的文档浏览 |
| `Tests.dc.html` | 测试与体验：用例总表与证据 |
| `canvas.json` | 画布上各页面的位置 |
